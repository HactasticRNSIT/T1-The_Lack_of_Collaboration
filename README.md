## ⚙️ Getting Started

### Prerequisites
- A modern web browser
- A [Supabase](https://supabase.com) account (for backend setup)

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/HactasticRNSIT/T1-The_Lack_of_Collaboration.git
   cd T1-The_Lack_of_Collaboration
   ```

2. **Configure Supabase**
   - Create a new project on [Supabase](https://supabase.com)
   - Copy your **Project URL** and **Anon Key**
   - Update `supabase-client.js` with your credentials:
     ```js
     const SUPABASE_URL = 'your-supabase-url';
     const SUPABASE_ANON_KEY = 'your-anon-key';
     ```

3. **Open in browser**
   - Simply open `index.html` in your browser, or
   - Deploy to Netlify by connecting the repository
